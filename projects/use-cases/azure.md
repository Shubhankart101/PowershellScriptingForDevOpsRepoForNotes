# Azure PowerShell use cases

## Resource operations

- Use Az PowerShell or Azure CLI from PowerShell for inventory, tags, resource groups, deployments, and policy checks.
- Add `-WhatIf`, managed identity, retry handling, exit-code checks, and structured JSON output.

## CI/CD and application delivery

- Automate App Service, Container Apps, AKS, Key Vault, deployment slots, environment variables, and release validation.

## Monitoring and incident response

- Query Azure Monitor and Application Insights, collect diagnostics, correlate incidents, and generate evidence packages.

## Governance

- Report RBAC, tags, policy compliance, secrets boundaries, cost signals, and drift for approved remediation.
