# AWS PowerShell use cases

## Resource operations

- Use AWS Tools for PowerShell to inventory EC2, S3, IAM, VPC, ECS, EKS, and RDS resources.
- Normalize cloud responses as objects and export safe JSON or CSV reports.

## CI/CD and application delivery

- Automate deployment metadata, ECR/ECS workflows, Lambda packaging, approvals, and rollback validation.

## Monitoring and incident response

- Query CloudWatch, collect instance diagnostics, inspect security groups, and create structured incident summaries.

## Governance

- Check tags, IAM boundaries, encryption, public exposure, backup settings, and cost-control policies.
