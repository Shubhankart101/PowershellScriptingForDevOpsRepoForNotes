# On-premises PowerShell use cases

## Windows and virtualization operations

- Automate Windows Server, Hyper-V, VMware, services, scheduled tasks, certificates, storage, and event logs.

## Hybrid operations

- Coordinate private infrastructure with Azure and AWS using secure remoting, identity, DNS, routing, and inventory workflows.

## Configuration and compliance

- Compare baselines, report drift, patch systems, validate security settings, and apply approved changes with `-WhatIf`.

## Reliability and incident response

- Collect diagnostics, preserve logs, run health checks, coordinate recovery, and produce audit-ready reports.
