# Configuration and compliance

## Use case

Compare machine or cloud configuration against a desired baseline, report drift, and apply only approved changes.

## PowerShell focus

- Desired-state objects
- File, registry, service, and process checks
- Compliance JSON and CSV reports
- `-WhatIf` and approval boundaries
- PSScriptAnalyzer and Pester quality gates

## Advanced direction

Version baselines, sign scripts, centralize policy definitions, integrate compliance results into CI/CD, and route exceptions through governance.
