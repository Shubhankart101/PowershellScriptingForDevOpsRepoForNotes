# Monitoring and incident response

## Use case

Collect application and infrastructure diagnostics, query monitoring APIs, summarize incidents, and create evidence packages for escalation.

## PowerShell focus

- Structured JSON logs
- Azure Monitor and Datadog API calls
- Time-windowed diagnostics
- Retry and timeout handling
- Incident summaries and evidence files

## Advanced direction

Use correlation IDs, parallel collection, secure API authentication, retention controls, and automated ticket or notification integration.
