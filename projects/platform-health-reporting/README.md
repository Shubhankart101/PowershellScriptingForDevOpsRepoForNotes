# Platform health reporting

## Use case

Create a repeatable health report across services, virtual machines, storage, databases, endpoints, and deployment environments.

## PowerShell focus

- Object pipelines and calculated properties
- REST and CLI data collection
- CSV, JSON, and HTML reports
- Scheduled reporting
- Threshold and status evaluation

## Advanced direction

Publish reports to dashboards, add trend comparisons, correlate incidents, and integrate with Grafana, Datadog, Azure Monitor, or notification systems.
