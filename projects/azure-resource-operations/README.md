# Azure resource operations

## Use case

Automate Azure inventory, resource-group checks, tag compliance, deployment-state checks, and controlled cleanup across subscriptions.

## PowerShell focus

- Azure CLI and Az PowerShell integration
- Subscription and resource-group iteration
- `-WhatIf` safety boundaries
- Exit-code and exception handling
- CSV/JSON reporting

## Advanced direction

Use managed identity, parallel inventory, retry policies, Azure Resource Graph, policy remediation, and approval-gated changes.
